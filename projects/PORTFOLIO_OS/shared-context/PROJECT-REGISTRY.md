## Maturity Key

| Status | Meaning |
|--------|---------|
| `idea` | Project described but not yet evaluated |
| `reviewed` | Initial evaluation complete |
| `refined` | Markdown files improved after evaluation |
| `shortlisted` | Curator selected as build candidate |
| `selected` | Actively being built |
| `implemented` | Core version working |
| `archived` | Deprioritized or superseded |
| `falsified` | Core assumption proven wrong |
| `superseded` | Replaced by a better approach |

---

## Update Instructions

When updating this registry:

1. Update the **Maturity** field when project status changes
2. Update **Last Evaluated** with the date of the most recent `EVALUATION.md` update
3. Update **EVAL.md** to `yes` once the file exists
4. Update **Priority** after each Curator recommendation

Keep one row per project. Do not delete rows — change status to `archived` or `falsified` instead.
