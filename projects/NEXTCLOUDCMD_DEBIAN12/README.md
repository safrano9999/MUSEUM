# NEXTCLOUDCMD Debian 12

Builds a relocatable, headless `nextcloudcmd` runtime for Debian 12 x86_64.
The bundle is built from Debian's supported `nextcloud-desktop-cmd` package and
smoke-tested in a clean Debian 12 image before release.

Release files:

```text
nextcloudcmd-debian12-x86_64.zip
nextcloudcmd-debian12-x86_64.zip.sha256
```
