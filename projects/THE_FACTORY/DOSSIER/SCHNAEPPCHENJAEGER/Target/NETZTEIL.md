## 📊 Strombedarf Berechnung

```
2x RTX 4090:    2 × 450W = 900W
CPU (Ryzen 9):           = 170W
Motherboard:             =  50W
RAM:                     =  30W
Storage / Lüfter:        =  50W
─────────────────────────────────
Total:                   ≈ 1.200W

+ 25% Reserve           ≈ 1.500W
→ Empfehlung: 1.600W PSU
```

## 💡 12VHPWR Kabel Hinweis

RTX 4090 braucht 12VHPWR (600W) Anschluss.
Immer **original PSU-Kabel** oder zertifizierte Adapter nutzen!
Billiges Adapterkabel = Brandgefahr!

```
Empfehlung: CableMod 12VHPWR Kabel
→ 1x 16-pin zu 4x 8-pin
→ Pro GPU eines
```
