# 🗄️ Tower / Gehäuse

**Ziel:** Platz für 2x Triple-Slot GPU + gute Belüftung
**Recherche-Datum:** 2026-03-01

---

## ⚠️ Anforderungen Dual GPU

- **Mindestens 3 freie PCIe Slots** nebeneinander
- **Breite:** RTX 4090 FE = 3 Slots → braucht viel Platz
- **Länge:** RTX 4090 bis 340mm lang → Case muss das erlauben
- **Airflow:** 2x 450W erzeugen massive Hitze → gute Belüftung essentiell
- **Form Factor:** E-ATX oder großes ATX bevorzugt
