# SIGNAL-LOG.md — Trend and Signal Log

Maintained by the Scout (Pulse 📡). Updated after each scouting session.

---

## Purpose

Store durable signal observations over time. Help the team notice recurring themes, trend quality, format opportunities, and saturated topics.

This is not a raw dump. This is a structured memory of useful signals.

---

## Entry Format

```
### S-XXXX
**Date:** YYYY-MM-DD
**Source:** X / Reddit / Threads / LinkedIn / creator cluster
**Category:** rising trend / saturated / controversy / meme format / pain point / recurring theme / engagement trap
**Summary:** One sentence describing what is happening.
**Why it matters:** Why this may matter for the account.
**Relevance:** high / medium / low
**Risk:** low / medium / high
**Recommended action:** ignore / monitor / test one post / build thread / turn into series / reply only / avoid
```

## Logging Rules

- Log only signals that may matter beyond a single moment
- Distinguish novelty from actual usefulness
- Prefer context over hype
- Record why something was rejected, not just what was chosen
- Use this file to build memory and pattern recognition, not just urgency
